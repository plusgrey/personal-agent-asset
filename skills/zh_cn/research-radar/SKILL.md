# 研究雷达

## 工作流
1. 确认范围、时间窗和证据门槛；默认最近 14 天、优先一手来源。
2. 广泛检索，再按标题、DOI/arXiv ID 和核心贡献去重。
3. 对每项记录来源、日期、主张、证据、局限和相关性。
4. 按新颖性、证据质量、实践影响、个人匹配度各 1-5 分；不能只看标题评分。
5. 输出 **立即行动 / 持续观察 / 归档**，每项给一个下一步。
6. 明确标注无法访问或未核验的来源，绝不编造引用。

## 示例
请求：“生成本周市场微观结构和 LLM Agent 雷达。”

条目：
- **持续观察——自适应执行 Agent**（15/20）
- 证据：2026-10-30 发布的 arXiv 预印本，仅有仿真。
- 意义：在线估计冲击并更新工具调用策略。
- 局限：没有实盘验证。
- 下一步：在一个月本地订单簿数据上复现成本模型。

用 `python -m automations.run research-radar --dry-run` 安全预览；采取行动前人工核验证据。
